# Tema 12: Conceptos y fundamentos de los sistemas operativos

Conceptos y fundamentos de los sistemas operativos. Características técnicas, funcionales y de administración: Windows, Linux, Unix y otros. Sistemas operativos para dispositivos móviles.

## Conceptos y fundamentos de los sistemas operativos

### Conceptos, funciones y administración

El sistema operativo (SO) gestiona el hardware y ofrece abstracciones y servicios a aplicaciones y usuarios. Sus componentes incluyen núcleo, llamadas al sistema, controladores, gestor de memoria, planificador, sistema de archivos, red, servicios y herramientas de administración. Gestiona procesos e hilos, memoria virtual, dispositivos, permisos y concurrencia. Los objetivos son eficiencia, aislamiento, disponibilidad, seguridad y facilidad de uso.

Un proceso es una instancia de programa con espacio de direcciones y recursos; los hilos comparten recursos del proceso. El planificador asigna CPU; la memoria virtual separa direcciones lógicas y físicas, y el sistema de archivos organiza datos y metadatos. La administración incluye cuentas y grupos, privilegios mínimos, configuración de servicios, actualizaciones, registros, copias, cuotas, automatización y monitorización.

### Familias de sistemas

Windows ofrece integración con Active Directory, servicios, registro, NTFS y herramientas gráficas y de línea de comandos. Linux y Unix siguen principios multiusuario y multitarea; Linux usa distribuciones y componentes GNU, permisos POSIX, shell y sistemas de paquetes. Unix designa una familia de sistemas y estándares, no una única implementación. Se distinguen núcleos monolíticos y micronúcleos, sistemas de tiempo compartido, tiempo real y embebidos.

### Sistemas móviles

Android se basa en el núcleo Linux y un entorno de aplicaciones; iOS es la plataforma móvil de Apple. Ambos aíslan aplicaciones, gestionan permisos y distribuyen software mediante tiendas firmadas. La administración empresarial incorpora cifrado, arranque seguro, actualizaciones, políticas, borrado remoto y gestión MDM/EMM/UEM.
