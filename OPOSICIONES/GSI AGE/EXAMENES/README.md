# Exámenes GSI AGE

Cuestionarios, supuestos prácticos y plantillas de corrección descargados de las páginas de ingreso libre del INAP. Los ficheros están agrupados por convocatoria; consulta las páginas enlazadas en la aplicación para avisos, correcciones y publicaciones posteriores.

La carpeta `JSON` contiene doce exámenes históricos en formato JSON para hacer test. Las plantillas definitivas oficiales de 2008, 2011, 2013, 2018, 2019, 2022 y 2024 permiten la corrección automática; los exámenes sin plantilla se practican sin puntuación.
